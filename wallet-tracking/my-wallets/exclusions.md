# Exclusions

Cielo lets you exclude specific tokens or contracts from triggering alerts. This is useful when a token or contract keeps generating noise transactions you don't want to be notified about, for example a rewards contract that sends tokens back to users, or a token you're no longer interested in tracking.

Unlike Token Filters, which control which assets you _do_ want alerts for, Exclusions block a specific address entirely, no matter which role it plays in the transaction (sender, receiver, pool, router, or the token itself).

To set an exclusion, go to **Tracking > Exclusions**.

In the **Add exclusion** field, select the chain and paste the token or contract address you want to exclude, then click **Add**. You can exclude addresses on Ethereum, Base, Solana, and Robinhood.

Once added, the exclusion applies automatically across all your tracked wallets, you don't need to configure it per wallet or per alert.\
\
You can add up to 200 exclusions, and remove any of them at any time from the same list.
